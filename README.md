# 電験三種 学習帳

第三種電気主任技術者試験（理論・電力・機械・法規）の学習用 Web アプリです。
スマホで見ることを前提に、HTML / CSS / JavaScript だけで作っています（ビルド不要・サーバ不要）。

- 公開URL（GitHub Pages を有効にした後）：https://takumu9246.github.io/denken-study/

## できること

| 画面 | 内容 |
|---|---|
| ホーム | 試験日カウントダウン、受験する科目の選択（科目合格済みを外せる）、次のレッスン、科目別の推定点、学習プラン |
| レッスン | 40 レッスン（理論12・機械11・電力9・法規8）。「まずは概要 → 試験のポイント（公式・図）→ よく出る例題5問 → 関連問題」 |
| 問題 | 243 問（5 択、うち過去問類題 205 問）。ランダム／過去問類題／未学習／苦手／全問 |
| 計算 | 27 種類の計算ドリル。数値が毎回変わり、誤答は「よくある間違い」の計算結果 |
| 傾向 | 過去 15 回の分析：テーマ別の出題数、問題番号×試験回のテーマ表、問題番号ごとの定番テーマ |
| 到達度 | 科目ごとのテーマ別の習得度と推定点、学習記録、バックアップ |

用語（約 350）は本文中でタップすると説明が出ます。学習記録はこの端末のブラウザ（localStorage）に保存されます。

## 過去問分析

電気技術者試験センターが公表している平成28年度〜令和8年度上期の 15 回分の問題用紙から、各問の出題テーマを分類しました。
結果と方法は [docs/ANALYSIS.md](docs/ANALYSIS.md) を参照。

## 公開方法

Settings → Pages → Branch: `main` / `(root)` を選んで保存。

## 更新するとき

データやコードを直したら、`index.html` の `?v=` と `APP_VERSION`、`sw.js` の `CACHE` の版を上げてから commit / push してください（スマホに古い版が残らないようにするため）。

## ファイル構成

```
index.html / style.css / sw.js / manifest.json / icon*
js/base.js      科目の定義・共通ヘルパー
js/riron.js     理論のレッスンと問題（LESSON() で1レッスンずつ定義）
js/denryoku.js  電力
js/kikai.js     機械
js/hoki.js      法規
js/build.js     レッスン定義から LESSONS / QUESTIONS / INTROS / EXAMPLES を組み立てる
js/glossary.js  用語集
js/figures.js   図（インライン SVG）
js/trend.js     過去問分析の結果（tools/gen_trend.py で生成）
js/notes.js     要点まとめ・傾向コメント
js/plan.js      学習プラン
js/calc.js      計算ドリル
js/app.js       画面ロジック
docs/ANALYSIS.md 過去問分析の結果
tools/          分析に使ったスクリプト
```

## 注意

問題・解説はアプリ作成者（AI）が過去問の傾向をもとに作成したものです。法令の数値や試験制度は、
電気技術者試験センター・経済産業省などの公式情報で必ず確認してください。
