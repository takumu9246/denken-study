# 過去問分析（平成28年度〜令和8年度上期・15回分）

出典：電気技術者試験センター（www.shiken.or.jp）が公表している第三種電気主任技術者試験の問題用紙・解答。

## 方法

1. 公表 PDF を取得（H28〜R3 は画像 PDF のため tesseract（jpn）で OCR、R4 上期以降はテキスト抽出）
2. 「問N」で分割し、各問の冒頭文を取り出す（`tools/heads.py`）
3. 冒頭文のキーワードで出題テーマを判定し、誤判定を目視で補正（`tools/classify2.py`）
4. 科目ごとに「何回出たか（15回中）」「合計何問か」「どの問題番号に出るか」を集計し、`js/trend.js` を生成（`tools/gen_trend.py`）

分類結果の全データ：`docs/classification.json`（科目 → 試験回 → 問題番号 → テーマ）

> 注意：キーワードによる自動判定のため、境界的な問題（例：コンデンサを含む交流回路）は別のテーマに数えられていることがあります。傾向をつかむための目安です。
